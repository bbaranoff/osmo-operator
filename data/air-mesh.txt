# air-mesh.txt - who hears whom on the burst mesh (read by pont/airmesh.py).
#
# One edge per line:
#     <node a> <node b> <attenuation dB> [uni]
#
# Without the trailing word "uni" the edge applies in BOTH directions. With it,
# it only applies from a to b: useful for a node that transmits strongly but
# receives poorly, or to force a one-way handover.
#
# A PAIR ABSENT FROM THIS FILE CANNOT HEAR EACH OTHER. This is what makes a
# mesh rather than a bus: without the graph every mobile would hear every BTS
# of the bench at full power and there would be no cell, no reselection,
# nothing to demonstrate.
#
# Orders of magnitude: the RSSI announced by the BTS is around -60 dBm and the
# airmesh floor is -110 dBm by default, so:
#     10-25 dB    two neighbouring cells, both readable - reselection
#     30-45 dB    distant cell, readable but worse than the neighbour
#     ~50 dB      at the limit: a mobile hesitates, then drops
#     > 50 dB, or no line at all: out of range
#
# Constraint: this file is NOT reloaded at runtime; airmesh loads it at startup.
# Changing it requires restarting airmesh, not the whole stack.

# 3 is the VM: further away, readable from 2 only.
