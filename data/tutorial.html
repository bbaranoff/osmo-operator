osmo-operator — démarrage rapide

Réseau GSM/EGPRS complet sur une machine : BTS, cœur de réseau, Asterisk et softphones.

1. Lancer

Double-cliquez le téléphone rouge sur le bureau. Quatre fenêtres s'ouvrent, une par quart d'écran :

Terminalle banc démarre (start-direct.sh)
Firefoxconsole web sur 127.0.0.1:8080
WiresharkGSMTAP, udp/4729
Linphonepostes 100 et 200, déjà enregistrés

Comptez une à deux minutes avant que la radio soit stable.

2. Passer un appel

Dans Linphone, composez un numéro et décrochez :

NuméroDestination
100Linphone A
200Linphone B
600test d'écho — votre voix vous revient
500 / 700annonces enregistrées
1001XXun mobile GSM du réseau local

Depuis un mobile GSM, tout passe par le VTY de la console web, pas par un clavier : dans la barre en haut, choisissez l'opérateur (OP1), puis le mobile (BB MS1 ☎ …), et cliquez Go. Vous obtenez son terminal, d'où l'appel se compose :

Commande VTYEffet
call 1 100le mobile appelle Linphone A
call 1 hangupraccrocher
call 1 answerdécrocher un appel entrant

Le 1 est le nom du mobile, celui de mobile.cfg. En cas de doute, list dans le VTY affiche les commandes réellement disponibles.

Commencez par le 600. S'il vous répond, la chaîne SIP et l'audio sont bonnes — inutile de chercher plus loin côté téléphone.

3. Vérifier

  • Les postes sont enregistrés : asterisk -rx "pjsip show endpoints" → Avail
  • Le mobile est attaché : la console web, page Abonnés
  • La radio parle : Wireshark défile en continu sur udp/4729

4. Si ça coince

Linphone ne s'enregistre pas. Il ne relit jamais sa configuration à chaud : il faut le redémarrer. Un compte modifié pendant qu'il tourne n'est pas pris en compte, et il réécrit le fichier en quittant.

  • Appel muet. Le micro passe par la carte son, pas par le navigateur : pactl list short modules | grep loopback doit montrer deux lignes.
  • Écho. Les enceintes rentrent dans le micro — mettez un casque.
  • Pas de console web. systemctl status osmo-egprs-web, puis journalctl -u osmo-egprs-web.

5. Arrêter

sudo /opt/osmo-launch.sh stop, ou Ctrl+C dans le terminal du banc.
